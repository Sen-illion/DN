# StoryDiffusion Adapter

## Baseline nature
- multimodal visual storytelling baseline
- not a full branching interactive narrative engine

## Adapter strategy
- use DN benchmark visual subset only
- transform one benchmark item into a 3+ scene prompt sequence
- export generated image bundle and prompt bundle

## Expected main value
- visual consistency
- character consistency across scenes
- text-image alignment

## Execution note
- requires a CUDA-capable machine for serious benchmark runs
