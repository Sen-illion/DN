# Readwait Ablation

This folder collects threshold-sweep and read-wait on/off experiments.

Subfolders:
- `raw_runs/`: direct on/off run outputs
- `summaries/`: paired summaries, threshold tables, merged workbooks
- `reports/`: markdown writeups in Chinese
- `figures/`: plotted latency / scene-rate figures
- `scripts/`: runner scripts used for the readwait study
