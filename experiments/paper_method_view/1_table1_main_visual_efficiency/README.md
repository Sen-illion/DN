# Table 1: Main Experiment

Goal: show complete-system performance on visual and efficiency dimensions.

Subfolders:
- `visual_quality/`: image consistency and visual scoring materials
- `efficiency_metrics/`: latency and success summaries
- `raw_runs/`: representative raw run files for the complete system
- `summary_tables/`: candidate summary workbooks for the paper
- `supporting_reliability/`: repeatability and guardrail evidence that supports Table 1
- `baselines/`: currently mostly empty because final baseline comparisons are still missing
