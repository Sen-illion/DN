\section{Visual Quality Evaluation}
\label{sec:visual-quality}

This section evaluates whether the images delivered by each system are usable for interactive narrative play. While Section~\ref{sec:efficiency} measures how quickly a system can deliver the next playable state, visual quality measures whether the delivered image follows the requested narrative theme and whether the visual world remains aesthetically stable across turns.

\paragraph{Protocol.}
We evaluate the same formal20 benchmark used in the efficiency study. For DN, we use the pre-generation full-ready outputs from the main setting. For StoryDiffusion, SDM-v2, and IC-LoRA, we use their existing formal20 first-turn and next-turn image outputs. No image is regenerated for this evaluation. Each system contributes three image records per benchmark item: the first-turn image, the current image used for the next-turn continuation, and the next-turn image. This yields 60 image-level records per system and 240 image-level records in total.

\paragraph{Instruction following and theme alignment.}
For each image, a vision-language judge scores whether the visual output follows the benchmark theme, the current scene text, the requested image style, and visually checkable must-have constraints. The judge also records forbidden-issue violations such as visible watermarks, unintended text, style drift, or theme leakage. The primary holistic score is \emph{Instruction Following}, reported on a 1--5 scale.

\paragraph{Aesthetic consistency.}
For each system--benchmark-item group, the judge scores the three associated images jointly. The rubric covers style and lighting consistency, subject-attribute consistency, scene-world consistency, composition quality, and artifact severity. The primary holistic score is \emph{Aesthetic Consistency}, also reported on a 1--5 scale. This group-level evaluation is intentionally distinct from single-image appeal: it asks whether the same system preserves a coherent visual identity as the narrative advances.

\paragraph{Current status.}
The evaluation manifest has been built from existing formal20 artifacts. Image validation found one invalid zero-byte SDM-v2 first-turn image; all other image records are readable. Table~\ref{tab:visual-quality-main} reports a reproducible automatic proxy based on CLIP image--text similarity, zero-shot style ranking, cross-turn image-embedding consistency, color-histogram consistency, and low-level artifact checks. Because this proxy does not replace direct semantic inspection, the final version should confirm these numbers with VLM or human judges.
