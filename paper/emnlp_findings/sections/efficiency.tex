\section{Efficiency Evaluation}
\label{sec:efficiency}

\paragraph{Evaluation goal.}
We evaluate whether \dn can deliver next-turn content with practical latency while preserving consistent multimodal outputs. To keep one unified comparison surface, we report efficiency and consistency metrics in a single main table across the same baseline set.

\paragraph{Protocol and metrics.}
The current efficiency values use the formal20 setup with strict full-ready timing for \dn and next-turn image or workflow latency for image baselines. Consistency fields are kept in the same table schema but are marked as TODO until the Qwen3-based and DINO-v2-based runs are fully frozen under one script.
